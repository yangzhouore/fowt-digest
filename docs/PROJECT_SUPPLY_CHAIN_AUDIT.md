No schema extension. The adapter groups existing relationships into six presentation categories, retains status, scope, Industry IDs and source URLs, and rejects entries without valid source records. Historical entries have explicit labels, including on existing detail pages. No columns were added to the main comparison row.

Access dates are provenance dates, not project material-review dates. The dataset still lacks a reliable per-project review timestamp; none is inferred or added for presentation. The smallest generic future extension would be an optional `lastMateriallyReviewed` date on the curated intelligence record, written only when a curator completes a material review.
