# 英国浮式风电：从材料到兆瓦时

这是已接受英文内容的中文说明稿。证据复核日期为 2026-10-22；各主题使用与英文相同的来源。

## 1. 完整产业链：四种关系分开看

```text
工业交付：材料 → 零部件 → 子系统 → 工程／制造包 → 安装集成 → 风电场
项目开发：海域权利＋调查＋许可＋设计＋并网＋收入＋资金 → 投资决定 → 建造 → 运行 → 退役
许可协调：海床管理方、审批机关、环境顾问、政府、Ofgem、NESO、市场规则
电力实物流：风电场 → 网络 → 用户
商业资金流：购电方 → 发电商；LCCC ↔ 发电商；网络收费另行结算
```

**通常做法／工程解读。** 下表是常见客户与责任关系，不是统一合同模板。开发商可以直接采购，也可以通过总包方采购。EPCI 指工程、采购、建造与安装；交给总包方的是约定范围内的责任，并非所有风险。

| 层级 | 向下一环节交付什么 | 通常谁向谁付款 | 主要风险 | 机构／企业示例与边界 |
|---|---|---|---|---|
| 材料 | 钢材、铜／铝、混凝土原料、复合材料纤维与树脂 | 零部件厂向材料加工方付款；加工方采购原料 | 价格、能源成本、来源与材料等级 | Tata Steel UK 参与浮式平台钢材研发；研发合作不等于风场供货合同 |
| 零部件 | 钢板构件、链条、绳索、缆芯、连接器、叶片和轴承 | 子系统供应商向专业制造商付款 | 疲劳质量、缺陷、认证与交期 | Bridon-Bekaert、Lankhorst 提供系泊线产品；系统规格由设计方确定 |
| 子系统 | 风机电气、定位保持、动态海缆组件 | OEM 或设备包牵头方向子系统供应商付款 | 兼容性、载荷、温升与验证 | 电气部件进入风机包后仍需 OEM 集成 |
| 工程／制造包 | 成套风机、浮体、系泊系统、电气网络 | 项目公司向 OEM、制造厂或承包商付款 | 设计变更、质保、生产节拍、成本 | Principle Power 提供浮式技术；制造与交付范围由合同确定 |
| 集成与海上交付 | 已安装、连接并测试的系统 | 项目公司或设备包承包方向港口、安装商、船东付款 | 天气、船期、损坏与接口进度 | Boskalis 有 Kincardine 运输安装案例 |
| 开发商／项目公司 | 获许可、有资金、合同协调完整的发电业务 | 股东投入开发资金／股权；贷款方可提供债务；项目公司支付采购款 | 开发失败、接口遗漏、收入和完工 | SPV 是持有项目和合同的特殊目的公司 |
| 输电设施 | 风场到电网的可用输电连接 | 传统开发商建设模式下，OFTO 按评估价值收购资产，以许可收入支持运营 | 海缆故障、可用率、移交与维修 | OFTO 是输电资产所有者，不是电力买家 |
| 电力系统与市场 | 实时平衡、网络接入与商业结算 | 买家向发电商付款；网络、平衡与偏差另有规则 | 预测误差、阻塞、停运与价格 | NESO 负责系统平衡；Elexon 管理 BSC 结算 |
| 公共协调与监管 | 权利、许可、政策与消费者保护 | 申请方可能支付费用或租金；监管方不是设备采购链顶端客户 | 环境可接受性、合规与政策变化 | 海床管理、建设审批、能源监管与政策制定是不同职责 |

## 2. 开发商是项目集成方

**通常做法。** 开发商不制造全部设备，而是使独立设备包构成一个能够建设、运行并获得收入的项目。以下是职责分组，不要求每个开发商有同样的部门；工作可以自有、借调、合资共享或外包。

| 职责组 | 涉及团队 | 协调内容 |
|---|---|---|
| 开发与交付控制 | 项目开发、项目管理／PMO（项目管理办公室） | 范围、进度、预算、决策与变更控制 |
| 一体化技术设计 | 工程、风机、浮式结构、系泊、动态海缆 | 共同设计基础、载荷、运动限值和接口 |
| 电气交付 | 电气系统、并网 | 阵列／送出网络、保护、合规与接入工程 |
| 许可与相关方 | 许可和环境、渔业和利益相关方、HSE（健康安全环境） | 设计包络、沟通、安全设计和安全作业 |
| 商业承诺 | 采购供应链、商业／CfD、项目融资、法律合同 | 价格、范围、责任、质保、收入、资金和预备金 |
| 建造与移交 | 施工、海上作业、调试 | 港口船舶、安装、测试、送电与移交 |
| 长期资产责任 | 运维、资产管理 | 可用率、检查、维修物流、完整性和寿命责任 |

FEED 是前端工程设计：形成整体方案和采购基础。项目管理把技术包、预算、建设与售电安排连接起来。

**工程解读。** 更大的风机会改变浮体载荷、系泊张力、海缆偏移、起重能力、许可尺寸和融资成本。工程团队不能脱离商业、港口、审批和运维团队单独决定；应使用受控接口清单和跨团队变更评估。

## 3. 项目生命周期：决策有先后，工作常并行

这是一种典型决策顺序，不是法定清单。调查、许可、并网、收入与采购相互重叠，必要时返回前一步。部分预订或先期工程可在 FID 前进行，但应明确承担风险。

| 阶段／目标 | 技术活动 | 商业活动 | 主管机构或决策者 | 进入下一项承诺前的条件 |
|---|---|---|---|---|
| 海床租赁：取得开发权利 | 场址与约束筛选 | 投标及选择权／租赁协议 | The Crown Estate 或 Crown Estate Scotland | 明确权利和条件；不代表建设许可 |
| 场址调查：认识场址 | 风浪流、生态、水深、地球物理和取土 | 委托调查及数据使用权 | 适用的调查许可与环境机构 | 数据质量足以支持下一阶段设计与评估 |
| 概念选择：选可交付系统 | 风机／浮体／系泊／海缆／布置方案 | 比较全寿命成本与可交付性 | 开发商及顾问，并提前咨询主管方 | 优选方案与场址、港口和许可约束相容 |
| FEED：明确投资范围 | 耦合载荷、电气研究、接口设计 | 招标基础、合同策略和风险分配 | 开发商及设备包团队，按需独立审查 | 设计与成本足以支持报价和重大决策 |
| 许可：依法获准 | 环评、栖息地评估资料、减缓措施 | 土地权利与许可条件 | 各司法辖区主管方 | 获得必要决定，并有可执行的条件落实计划 |
| 并网：获得可行送出路径 | 接入设计、研究、网络加强 | 接入报价、费用、担保和日期 | NESO 与相应 TO／DNO | 明确实际协议义务和交付依赖 |
| 售电路径：建立收入 | 发电量及损耗预测 | 可选 CfD 竞拍、售电／PPA | DESNZ 政策、NESO 分配执行、LCCC 对手方及商业买家 | 收入安排可信；CfD 不等于实物售电 |
| 采购：取得可交付合同 | 技术规格、接口与验证 | 价格、范围、预订、责任和质保 | 项目公司及供应商 | 范围、价格、进度与产能承诺足够可靠 |
| 融资：为计划筹资 | 技术尽调与不利情景 | 股权／债务条款、保险和担保 | 投资者、贷款方及顾问 | 资金及先决条件已充分落实 |
| FID：授权投资 | 确认设计成熟度和交付计划 | 审批风险调整商业方案与资本 | 股东／项目公司投资治理 | 授权投资，剩余条件有人负责且可落实 |
| 制造：产出合格设备 | 详细设计、质量控制、制造和出厂测试 | 里程碑付款与变更控制 | 供应商、项目公司及约定认证方 | 设备验收与质量追溯证据 |
| 港口集成：组装风机和浮体 | 吊装、压载、接口与预调试 | 泊位、起重、湿储和物流合同 | 港务／港口机构及交付团队 | 稳定、经测试且可安全拖航和连接 |
| 安装：海上固定与连接 | 锚、系泊、海缆、拖航和连接 | 船舶执行、天气风险和索赔 | 适用海事许可、港务与安全主管方 | 安装完成并有检查测试证据 |
| 调试：验证功能 | 保护、通信、机电测试 | 验收、性能与移交 | 资产方及电网合规流程 | 安全送电授权与必要测试完成 |
| 发电：商业输出 | 计量、控制与性能 | 市场／BSC 注册、售电及 CfD 条件 | 网络和市场机构，必要时 LCCC | 按适用协议开展收入运行 |
| 运行：长期安全可用 | 风机和水下资产监测、检查、维修 | 运维合同、保险与寿命储备 | 业主、运营方与相应监管机构 | 持续完整性和合规，不是一次性关卡 |
| 退役：履行寿命末责任 | 拆除／保留评估、废物和监测 | 费用计提、担保与合同 | 英格兰／威尔士 DESNZ；苏格兰另有安排 | 按规定获批的方案、责任和资金，开发期即开始规划 |

关卡是工程和商业解读，不表示每一阶段都由监管方签字。来源包括调查、许可、接入、收入、安装与退役的对应指导。

## 4. 海床权利与建设许可由谁管理？

**已确认职责。** 选择权、租赁意向协议和租约属于财产权利／开发安排；建设许可依据法律批准特定活动。它们都不会自动提供并网、CfD 或资金。

| 地区 | 海床开发权利 | 海上许可 | 陆上工程与环境意见 |
|---|---|---|---|
| 苏格兰 | Crown Estate Scotland 管理相关苏格兰海床权利 | Scottish Ministers；MD-LOT 办理相应海事许可和《电力法》第 36 条同意 | 陆上审批另走适用程序；地方规划机关参与；NatureScot／JNCC 在各自范围提供自然保护意见 |
| 英格兰 | The Crown Estate | NSIP 由 Planning Inspectorate 审查、国务大臣决定 DCO；MMO 负责适用海事许可或视同许可相关管理 | 陆上工程可能纳入 DCO，或另需规划许可；Natural England 等提供意见 |
| 威尔士 | The Crown Estate | NRW 代表 Welsh Ministers 处理海事许可；发电审批可能走下放的基础设施许可或保留的 NSIP 路径，并考虑过渡安排 | PEDW、Welsh Ministers、地方规划机关按程序参与；NRW／JNCC 提供各自范围的环境意见 |

**制度变化。** 苏格兰 MD-LOT 指导更新于 2026-09-29；英格兰 MMO 指导于 2026-08-03 明确不能只按容量选择程序。威尔士 SIP 制度于 2025 年 12 月启动，当前指导涉及视同海事许可；英国 NSIP 指导解释威尔士海上发电 350 MW 边界等权限范围。位置、跨境设施、指令和过渡规则同样重要，不能把 2023 年流程图当成完整现行规则。

环境顾问为审批提供意见，不等于海床出租方或最终决策机关。

## 5. 从转子到海床

```text
风 → 叶片＋轮毂（转子） → 机舱内传动链／发电机 → 变流器 → 变压器 → 海缆
                          │
                         塔架
                          │
                         浮体
                    ┌─────┴─────┐
                  系泊线      动态海缆
                    │            │
                    锚         海床电缆／网络
                    │
                 海床／土体
```

**通常原理。** 叶片捕获空气动力能，转子带动传动链，发电机把机械能转为电能。机型可有齿轮箱，也可直驱。机舱容纳主要机械，塔架把上部载荷传到浮体。

浮体提供浮力和稳定性，系泊限制位移，锚把载荷传入土体。海床是设计条件，不是制造部件；海缆和系泊必须留出运动及安装空间。

| 概念 | 稳定机制 | 需要权衡的后果，而非统一排名 |
|---|---|---|
| 半潜式 | 分开的立柱／浮筒提供分布浮力 | 通常适合码头集成；占地、结构制造与港口空间重要；柔顺系泊允许的运动需由海缆承受 |
| Spar 深吃水柱式 | 深长结构与压载降低重心 | 大吃水限制港口和拖航，可能需要深水避风水域集成；运动和定位仍需场址分析 |
| TLP 张力腿式 | 过剩浮力由预张紧筋腱约束 | 可限制部分运动，但锚和筋腱承受上拔；运输安装阶段可能需临时稳定措施，海缆仍按实际响应设计 |

钢或混凝土、制造方式、水深、风机尺寸、港口和安装方法都影响结果。不存在对所有项目最便宜或最容易规模化的概念。

## 6. 沿电力路径走：电压与资产责任

**典型架构，并非每个项目的单线图。** 以下电压是示例，不是强制值。风、转子和海缆登陆点本身没有独立电压等级；变流器架构和变压器位置取决于机型。

| 环节 | 目的／设备 | 常见电压背景 | 资产方及工程问题 |
|---|---|---|---|
| 风 → 转子 | 叶片把风能转为扭矩 | 尚未产生电能 | 发电业主／OEM；风变化、尾流和载荷 |
| 发电机 → 变流器 | 发电与电气输出控制 | 风机内部，指导示例 0.69–3.3 kV | 发电资产；冷却、故障响应和控制 |
| 风机变压器 | 匹配阵列网络电压 | 例如升到 66 kV | 发电资产；质量、通道、绝缘和更换 |
| 动态阵列海缆 | 连接运动浮体与网络 | 与阵列额定电压相同，常见 66 kV | 通常属发电系统；弯曲、张力和疲劳 |
| 阵列海缆网络 | 汇集各风机回路 | 66 kV 常见，旧／新设计可不同 | 发电系统；载流、损耗、保护和故障影响范围 |
| 海上升压站（如有） | 汇集、升压或变换为直流 | 交流示例 66 → 220 kV | 传统 OFTO 范围下常在输电侧；设备重量与维护 |
| 海上送出海缆 | 向岸输送总功率 | 交流示例 220 kV；直流另定额定值 | 输电案例中先由开发商持有，再移交 OFTO；损耗、交流充电与维修 |
| 登陆点 → 陆上电缆 | 穿越海岸并继续向内陆送电 | 通常保持送出回路电压直至变压 | 电缆资产方；接头、土建、热、通行和栖息地 |
| 陆上变电站 | 变压、滤波、控制或直流转交流 | 接入可为 132／275／400 kV 等 | 须分清项目／OFTO 侧与 TO 侧间隔 |
| 并网点 | 规定的电气与合同接口 | 依接入协议 | 各资产方；保护、计量与合规 |
| GB 输电网 | 互联网络输送大规模电力 | 常见 275／400 kV，苏格兰也有 132 kV | NGET／SSEN Transmission／SP Transmission；容量与阻塞 |
| 配电 → 用户 | 降压并送至本地 | 多级较低电压，终端取决于用户 | DNO（配电网运营方）及用户设施；局部容量和保护 |

**分支。** 部分小型风场接入配电网，或不设海上站直接送出；油气设施电气化也可能另有电力终点。不能据此认定所有英国浮式项目都使用 OFTO 或相同用户路径。

## 7. 动态海缆为何必须从系统角度分析？

```text
浮体挂点＋弯曲控制
    ↓ 自由悬垂段
    ↑ 浮力模块托起的拱段（懒波形示例）
    ↓ 下部悬垂段
触地点区域 ↔ 随运动改变的海床接触
    → 静态海缆段／接头（如采用） → 阵列网络
```

**通常做法。** 挂点承接海缆，弯曲控制装置限制局部曲率；浮力模块塑造柔顺外形以吸收运动。懒波形只是方案之一。触地区域的接触位置随运动变化；动态到静态的过渡并非每个方案都有。

**工程解读。** 浮体改变海缆端部位置；系泊刚度、预张力影响偏移；海缆形状再影响曲率、张力和海床作用。因此必须使用相容的耦合响应、极端载荷、疲劳和适用故障工况。系泊负责定位，电缆不能当系泊线。

## 8. 阵列与送出网络

**通常做法。** 多台风机组成回路，多个回路接入汇集点。拓扑、开关和保护决定故障会切掉多少发电量。运动端需要动态段，允许静态敷设的位置可使用海床静态段。66 kV 是常见设计点，不是法规，也不代表全部已建项目。

HVAC 为高压交流，较长电缆会带来无功和充电效应；HVDC 为高压直流，需要较昂贵复杂的换流设备，但可能适合长距离或大容量送出。选择取决于容量、距离、损耗、网络设计和设备，没有统一的距离分界线。

埋设与防护需调查地层和路由；交叉段可能需要协议、间距和专项防护。敷缆、牵入、终端连接和测试都是工作范围，敷完不等于已调试可用。

## 9. 变电站实际做什么？

**通常做法。** 海上站连接阵列与送出回路。变压器改变交流电压；开关设备隔离电路；保护识别故障并切除适当设备；无功设备管理交流网络状态；控制、通信、辅助电源和计量支持运行。直流方案还需要换流。

陆上站把电力调节到并网所需状态；它与相邻 TO 设施即使在同一地区，也可能有不同产权和责任。

**不能从“风机是浮式”推导“海上站必须浮式”。** 可以采用适当位置的固定站、适合小型项目的直接送出，或连接其他海上设施。BVG／ORE 参考方案本身采用固定海上站。

## 10. OFTO：拥有海上输电连接

```text
开发商建设发电设施及相关输电设施
       ↓
Ofgem 评估移交价值并组织 OFTO 竞争招标
       ↓
获许可 OFTO 收购指定输电资产
       ↓
依许可和收入安排持有、管理这些资产
```

**传统开发商建设模式。** 发电范围通常包括风机与汇集系统；输电范围常包括送出连接、相关变电设备和至约定边界的陆上资产。边界依许可、技术分类和移交文件，不是固定在海岸线。

**项目示例。** Greater Gabbard OFTO 服务的是固定式风场。Equitix 说明其收入与资产可用性相关，并列出独立运维方；这是产权商业模式示例，不是浮式项目订单。

**制度变化。** Ofgem 2026 年 5 月早期／后期竞争 OFTO-build 咨询在本次复核时仍标为关闭、待决定。协调海上网络可能采用不同采购和交付方式；咨询方案不是已生效统一规则，也不能假设未来资产全走同样移交路径。

## 11. 开发商、OFTO、TO 与 NESO 各做什么？

| 角色 | 负责什么 | 不代表什么 |
|---|---|---|
| 开发商／项目公司 | 开发并持有或组织风场发电业务 | 不代表拥有 GB 电网 |
| OFTO | 持有许可指定的海上输电资产 | 不代表拥有风场或购买其电力 |
| 陆上 TO | 建设、维护并拥有自身输电网络 | 不等于统筹全 GB 调度和平衡 |
| NESO | 运行 GB 电力系统、协调接入并规划系统需求 | 不拥有输电网络，也不购买全部电力 |

NGET 负责英格兰和威尔士；SSEN Transmission 负责苏格兰北部；SP Transmission 负责苏格兰中南部。NESO 与这些资产方协作，使用响应、备用和平衡机制等手段，维持安全运行及约 50 Hz 频率。网络阻塞会限制发电侧向需求侧送电。

**制度变化。** 并网改革评估项目是否准备就绪、是否符合战略需求。Gate 1 不提供确定接入日期；符合 Gate 2 的项目可通过相应程序取得日期、接入点及队列位置，但仍须查看实际报价和网络加强义务。

## 12. 电力实物流与资金流

```text
实物：发电 → 互联网络 → 用电需求
商业：购电方／交易商／售电商 → 发电商（售电或 PPA）
      发电商 ↔ LCCC（符合条件的 CfD 差额）
      市场参与方 ↔ BSC 偏差结算
      网络收费与监管收入另行安排
```

PPA 是购电协议。商业买家并不拥有一条供特定电子专用的物理路径。预测用于安排售电，实发与合同头寸可能不同；Elexon 管理的 BSC（平衡与结算规则）用于核算偏差。结算以半小时为周期，不表示物理平衡每半小时才做一次。

NESO 的 Balancing Mechanism 接受发电／用电变化以实时运行系统。阻塞可能要求某地减发、另一地补发；限制发电的付款取决于具体行动与规则。

批发电价可以为负，但不保证所有发电商仍收到执行价。政府指导说明 AR4 起合同对负日前价格时段的差额支付有限制；具体合同版本与结算规则必须核对。

## 13. CfD：稳定收入，不是政府包购电力

**已确认结构。** DESNZ 制定政策，NESO 执行分配竞拍，LCCC 是政府持有的合同对手方。发电商仍需安排实物售电；CfD 按执行价与指定市场参考价的差额结算。

**仅作算术示例。** 假设 1 MWh 符合支付条件，执行价 £100/MWh，实际售电价恰好等于参考价。为说明原理暂不计损耗、费用、指数调整及支付排除规则。

| 参考价／假定售电价 | CfD 差额 | 简化合计收入 |
|---|---|---|
| £60/MWh | LCCC 向发电商支付 £40 | £60＋£40＝£100 |
| £140/MWh | 发电商向 LCCC 支付 £40 | £140－£40＝£100 |

实际售电价不等于参考价时，合计收入也会不同。CfD 减少一种价格风险，但风资源、停机、负价排除、偏差成本和交付义务仍在；CfD 本身不是融资决定。

**合同变化。** DESNZ 确认 AR7 起包括浮式风电在内的有关风能／太阳能采用 20 年 CPI（消费者价格指数）调整合同；不能把所有 CfD 都称为 15 年合同。

**有日期的结果。** 2026-01-14 AR7 官方结果列出 Pentland 92.5 MW、Erebus 100 MW 浮式获配容量；这不是已 FID 或已发电的证据，也不一定等于项目全部许可容量。

## 14. 融资与 FID：技术方案能否获得资金？

**通常做法／商业解读。** 股东承担有风险的前期开发支出；股权承担所有者风险，贷款方关注还款和不利现金流情景。项目融资主要依赖项目合同与现金流，资产负债表融资则依靠股东更广泛的财力，并非所有项目采用同一种结构。

重大投资前通常需使许可和土地权利、并网时序、技术、CAPEX（资本支出）、收入／购电、建造、运维、接口分工、保险和预备金足够成熟。FID 后仍可能有待落实条件；“成熟”不等于“没有风险”。合同打包方式改变开发商承担的风险。

**项目示例。** GBE 说明其于 2025 年 11 月与 National Wealth Fund、Scottish National Investment Bank 等共同投资 Pentland。早期资金支持开发，不能在无更多证据时称为已完成建设融资或 FID。

## 15. 港口与制造：生产线连接海洋

```text
浮体制造／组装 → 码头或湿储
→ 塔架 → 机舱 → 叶片 → 预调试
→ 必要的湿储 → 拖出
```

**适用于可整体拖航方案的典型流程。** 可使用岸上重吊等经设计的吊装方案；部件到港、结构完工、吊装、压载与测试需要协调。Spar 和 TLP 可能需要不同运输和集成方法。

港口适配是多项条件同时满足：吊重和幅度、码头承载、水深潮位、无障碍拖航通道、堆场、湿储及系泊、人员和重复生产节拍。制造港、集成港、中转港和运维基地不必是同一处。

**英国例子，不代表已预订。** DESNZ 于 2025 年 3 月宣布支持 Cromarty Firth 扩建；2026 年 3 月宣布对 Port Talbot 设计工程支持最高 £64 million。公告本身不证明全部未来产能已建成或分配。Haventus 对 Ardersier 的设施描述也应区分开发阶段。

## 16. 海上安装：两条工作面汇合

```text
海上调查／清理 ─┬→ 锚 → 预装系泊／测试 ─┐
               └→ 海缆／变电站工程 ─────┤
港口：组装 → 测试 → 拖出 ───────────────┤
                                      ↓
系泊连接 → 动态海缆连接 → 电气调试 → 获授权送电
```

这是典型逻辑，不是固定船期。拖轮、起锚／锚处理船、敷缆船、调查船、ROV（水下遥控机器人）及专业技术人员承担不同任务；锚、海缆和浮体设计决定具体设备与顺序。

**工程解读。** 拖航前应使海上准备、港口放行、天气窗口、拖航路线、系泊／海缆连接和应急方案一致。若送出系统未就绪，已安装风机也可能无法交付电力；作业窗口取决于持续时间及海况，而不只一个风速限值。

## 17. 运维与寿命末责任

**通常做法。** SCADA（监控与数据采集）和状态监测识别性能变化及故障。还需检查浮体、腐蚀保护、海生物、系泊、锚和动态海缆；利用 ROV、水下检查、维修船、备件和通道维持完整性。不同资产方可能各有服务合同。

**浮式特点。** 大部件更换可在海上进行，也可断开后拖回港口；两者都需检查断接和重连、临时系泊／海缆安排、吃水、港口吊机档期与停机损失。Principle Power 报告 Kincardine 有原位及拖回港口的大部件更换经验。

退役从开发期即应规划费用和责任。英格兰／威尔士与苏格兰指导不同；拆除、合理保留、监测和资金担保依获批方案和适用规则，不能保证每根锚和海缆都必然拆除。

## 20. 接口：单项合格也可能整体失效

**工程解读，不是对任何具名项目的故障判断。**

| 接口 | 必须协调什么 | 可能出错什么 |
|---|---|---|
| 风机 ↔ 浮体 | 载荷、控制、质量、塔架连接、通道 | 运动／加速度超限或控制相互作用 |
| 浮体 ↔ 系泊 | 导缆点、恢复力、偏移与故障 | 漂移过大、连接过载或通行困难 |
| 浮体 ↔ 动态海缆 | 挂点、运动包络、弯曲限值、牵入 | 疲劳、过弯、过拉或维修困难 |
| 系泊 ↔ 海床 | 土体、载荷方向、循环承载 | 锚固不足或无法施工 |
| 海缆 ↔ 海床 | 路由、防护、海床迁移、交叉 | 暴露、磨损、悬跨或外力损伤 |
| 阵列 ↔ 变电站 | 电压、保护、额定值、接地与控制 | 保护选择性或容量不匹配 |
| 海上网络 ↔ OFTO | 边界、测试、质保与通道 | 移交延迟或责任空缺 |
| OFTO ↔ 陆上 TO | 保护、可用性、开关操作 | 风场正常但送出不可用 |
| 开发商 ↔ NESO／网络方 | 接入条件、合规、加强工程时序 | 已建资产无法按时送电 |
| 开发商 ↔ 主管方／相关方 | 设计包络、证据、减缓与条件 | 重设计或条件落实延误 |
| 开发商 ↔ 港口／安装商 | 吃水、尺寸、节拍、拖航窗口 | 港口排队或船舶等待 |
| 开发商 ↔ 资金方 | 不利情景、风险分工、储备和条件 | 技术可行但融资无法完成 |

这些是由整体工程与项目管理原理形成的调查问题，不是量化风险评分。

## 21. 瓶颈：区分证据与推断

| 约束 | 证据能支持什么 | 项目仍需核验什么 |
|---|---|---|
| 电网 | NESO 按准备程度与系统需求改革接入队列 | 实际报价、加强工程、责任与日期 |
| 港口／制造规模 | 2026 年政府委托研究指出成熟浮式生产能力有限，并列候选港口 | 设施实际阶段、档期、吃水、吊重和节拍 |
| 钢材／制造 | 研究区分厚板、钢材生产与结构制造能力 | 材料等级、厚度、焊接质量与预订产能 |
| 系泊／锚 | 技术指导说明设计、材料和土体依赖及数量需求 | 合格供应商、产能、测试和安装资源；不编造全国缺口数量 |
| 动态海缆／人员 | ORE Catapult 研究指出电缆全寿命技能和培训需求 | 电压／疲劳验证、附件、工厂及合格技术人员 |
| 海缆／安装船 | 专业设备与适当天气窗口不可少 | 实际租船、区域同时需求与维修预案；不杜撰船队短缺数字 |
| 资金／可融资性 | 前期投资及合同风险选择说明技术成熟度不够决定投资 | 收入、范围、成本、不利情景和融资条件 |
| 许可／环境 | 需要影响评估并提前获得顾问意见 | 鸟类、海兽、底栖、渔业、累积影响与条件 |
| 本地化 | CES 提供供应链发展声明与展望看板 | 把愿景、承诺、预测与已发生支出／已交付含量分开 |

这些不是统一的短缺排名或市场预测。各结论必须使用相应研究和主管方证据，单个项目要再查自身合同与时序。

## 22. 记忆框架与十五个问题

```text
海床权利＋许可＋电网＋收入＋资金
＋可交付技术＋供应链＋港口／海上方案
                 ↓
             最终投资决定
                 ↓
       制造 → 集成 → 安装
                 ↓
           调试 → 发电
                 ↓
         输电／配电 → 用户
资金流另看：售电、网络收费、CfD 与偏差结算
全程贯穿：安全、相关方、资产完整性、运维和退役资金
```

这是解释框架，不是统一法定顺序。运维是跨数十年的责任，设计寿命、租约期限和补贴合同期限是不同数字，需按项目核验。

1. 谁持有海床权利，有什么附带条件？
2. 谁拥有项目公司，谁负责开发？
3. 海上与陆上许可哪些已有、哪些仍有条件？
4. 当前并网协议提供什么接入点、容量和日期？
5. 电力物理上送去哪里，商业上卖给谁？
6. 是否有 CfD，覆盖哪个容量、轮次和合同条件？
7. 风机是已明确、已选择还是仅假设？
8. 什么浮体概念适配场址与港口？
9. 土体和耦合载荷是否支持系泊／锚方案？
10. 海缆是否满足电压、运动与疲劳要求？
11. 哪些港口和船舶实际可用或已有合同？
12. 集成、拖航、连接与送电怎样衔接？
13. 发电、OFTO、TO 的资产边界在哪里？
14. 什么证据说明融资／FID 成熟，而不仅是获得开发资金？
15. 如何为检查、大修、海缆故障和退役提供资金与交付安排？
